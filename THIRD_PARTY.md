# Third-party components

- **pdf-lib 1.17.1**, MIT, https://github.com/Hopding/pdf-lib. License: `vendor/pdf-lib-LICENSE.md`.
- **@pdf-lib/fontkit 1.1.1**, declared MIT by the published npm package, https://github.com/Hopding/fontkit. The package omitted a standalone license file; its README and attribution are retained in `vendor/fontkit-README.md` and `vendor/fontkit-NOTICE.txt`.
- **pako**, embedded in fontkit, MIT/Zlib; license: `vendor/pako-LICENSE.txt`.
- **Bitstream Vera**, synthetic-test font only, copyright Bitstream, Inc.; redistribution license: `tests/fixtures/bitstream-vera-license.txt`.

Runtime libraries are bundled locally; no remote scripts or fonts are loaded. Personal resumes and API keys are not part of this repository.
